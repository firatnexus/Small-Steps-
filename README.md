## ✨ Özellikler

- 📝 **Görev listesi** — ekle, tamamla, düzenle, sil, geri al
- 🔎 **Filtreler** — Tümü · Aktif · Tamamlanan
- 📊 **İlerleme çubuğu** ve günlük istatistik
- ⏱️ **Pomodoro** — Odak · Kısa mola · Uzun mola, otomatik geçiş
- 🌍 **12 dil** — Türkçe, İngilizce, Almanca, İspanyolca, Fransızca, İtalyanca, Portekizce, Rusça, Arapça (RTL), Hintçe, Japonca, Çince
- 🌗 **4 tema** — Aydınlık · Karanlık · Sepya · Yüksek kontrast
- ⌨️ **Klavye kısayolları** — `Space`, `N`, `Esc`
- 🔊 **Sesli uyarı** + 🔔 **masaüstü bildirimi**
- 📱 **PWA** — ana ekrana kurulabilir, çevrimdışı çalışır
- 💾 **localStorage** — sunucu yok, hesap yok
